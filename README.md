# Подсчет транспорта и распознавание номеров

Решение для задания по компьютерному зрению: YOLOv8 детектирует транспорт, BoT-SORT сохраняет ID объектов между кадрами, отдельная YOLO-модель находит номерные таблички, а EasyOCR пытается распознать текст номера.

## Что делает скрипт

- Детектирует транспортные средства: `car`, `motorcycle`, `bus`, `truck`.
- Трекает объекты через встроенный `botsort.yaml`.
- Считает пересечения заданной линии только в выбранном направлении.
- Не считает один и тот же `track_id` повторно.
- Отрисовывает bbox транспорта, ID, класс, центр объекта и номер.
- Отдельно отрисовывает bbox найденной номерной таблички фиолетовым цветом.
- Записывает результат в видео и CSV-отчет.
- Обрабатывает видео с пониженным FPS, по умолчанию `15`, чтобы снизить нагрузку.

## Подготовка окружения

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

В проекте используется один файл зависимостей: `requirements.txt`.

## Модели

Для транспорта используется стандартная COCO-модель YOLOv8:

```text
yolov8n.pt
```

Для номерных знаков добавлена готовая модель:

```text
models/license_plate_detector.pt
```

Источник модели номеров: `Koushim/yolov8-license-plate-detection` на Hugging Face.

## Запуск

Пример для видео `1280x720`, где транспорт движется сверху вниз через горизонтальную линию:

```bash
python count_cars.py \
  --input input/traffic.mp4 \
  --output output/output_counted.mp4 \
  --csv output/crossings.csv \
  --line-start 0,420 \
  --line-end 1280,420 \
  --direction top-to-bottom \
  --target-fps 15
```

Распознавание номеров теперь включено всегда, поэтому отдельный флаг `--enable-plates` больше не нужен.

Если нужно увидеть обработку в реальном времени:

```bash
python count_cars.py \
  --input input/traffic.mp4 \
  --output output/output_preview.mp4 \
  --csv output/crossings_preview.csv \
  --line-start 0,420 \
  --line-end 1280,420 \
  --direction top-to-bottom \
  --target-fps 15 \
  --show
```

Нажмите `q`, чтобы закрыть окно предпросмотра.

## FPS

Скрипт преднамеренно не прогоняет трекер и OCR на каждом кадре исходного видео. По умолчанию используется:

```bash
--target-fps 15
```

Для тяжелого видео можно снизить:

```bash
--target-fps 10
```

Для более плавного результата можно увеличить:

```bash
--target-fps 20
```

## Классы транспорта

По умолчанию используются COCO-классы:

```text
2 car
3 motorcycle
5 bus
7 truck
```

Если нужно оставить только автомобили:

```bash
--classes 2
```

Если нужно добавить велосипеды:

```bash
--classes 1,2,3,5,7
```

## Линия подсчета

Координаты задаются в пикселях исходного видео:

- `--line-start x1,y1` - первая точка линии.
- `--line-end x2,y2` - вторая точка линии.

Для видео `1280x720`:

- вертикальная линия по центру: `--line-start 640,0 --line-end 640,720`;
- горизонтальная линия ниже середины: `--line-start 0,420 --line-end 1280,420`.

Направление задается параметром `--direction`:

```text
left-to-right
right-to-left
top-to-bottom
bottom-to-top
```

## Результаты

После выполнения появятся:

- `output/output_counted.mp4` - видео с визуализацией;
- `output/crossings.csv` - отчет по пересечениям.

CSV содержит:

```text
frame,time_seconds,track_id,class_name,center_x,center_y,plate_text
```

Если номер плохо виден на видео, `plate_text` может быть пустым или неточным, но фиолетовая рамка `plate` на выходном видео показывает, как сработал детектор номерной таблички.
